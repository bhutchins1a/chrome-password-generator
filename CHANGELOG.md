# Changelog

## 1.3

- Guaranteed at least one uppercase letter.
- Guaranteed at least one lowercase letter.
- Continued to generate exactly one digit.
- Continued to generate exactly one allowed special character from `!@#$&_-`.
- Improved handling of Chrome internal/protected pages when auto-insert is enabled.

## 1.2

- Added exactly one digit.
- Added exactly one special character from `!@#$&_-`.
- Retained adjustable 10-20 character length.
- Retained automatic clipboard copying and optional auto-insert.

## 1.1

- Letter-only password generation.
- Adjustable length.
- Automatic clipboard copying.
- Optional insertion into the focused field.
- Keyboard shortcut support.
